Hi font fanatics! Anyone hungry for an old time classic? I've had this juicy idea in my head for years and finally broke down and did something about it. Wendyville is an excellent choice if 
you're looking for a clean western style font or designing a custom WANTED poster. This baby contains a full character set with punctuation, symbols, and many others. Lowercase letters are the
same as uppercase with the exception of m, n, and the y, which are different in appearence. The { and } will produce decorative curves that compliment your type. Feel free to redistribute as 
long as this readme file stays intact. This font is free for personal use only. For commercial use please contact me at dennis@sharkshock.net to discuss an end user license. I also design custom
fonts, logos, and many other things.
